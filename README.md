## 🚀 Featured Projects

### 01. SPK Pemilihan Lokasi Co-working Space

Sistem Pendukung Keputusan untuk membantu menentukan lokasi co-working space terbaik menggunakan integrasi metode AHP dan SAW.

**Features:**
- Pengelolaan alternatif lokasi.
- Pengelolaan kriteria penilaian.
- Perhitungan bobot menggunakan AHP.
- Perhitungan normalisasi menggunakan SAW.
- Perankingan alternatif berdasarkan nilai preferensi.

**Tech Stack:** PHP, MySQL, JavaScript, CSS, AHP, SAW.

---

### 02. SIAP PANEN

Aplikasi sistem informasi untuk membantu pengelolaan data komoditas pertanian dan informasi ketersediaan hasil panen.

**Features:**
- Informasi komoditas panen dan akan panen.
- Pengelolaan data berdasarkan kecamatan.
- Informasi status ketersediaan hasil panen.
- Peta persebaran komoditas.
- Laporan PDF dan Excel.

**Tech Stack:** Python, Flask, HTML, CSS, JavaScript.

---

### 03. Mobile IoT: Flutter + ESP32

Proyek integrasi aplikasi Android dengan perangkat ESP32 melalui Bluetooth Low Energy (BLE) dan MQTT.

**Features:**
- Kontrol LED melalui BLE.
- Monitoring suhu dan kelembapan DHT22.
- Komunikasi perangkat menggunakan MQTT.
- Integrasi aplikasi mobile dengan ESP32.
- Pengujian latensi komunikasi.

**Tech Stack:** Flutter, Dart, ESP32, BLE, MQTT, Arduino IDE.

---

### 04. Sistem Informasi Audit Mutu Internal (AMI)

Pengembangan sistem informasi untuk mendukung proses Audit Mutu Internal pada perguruan tinggi.

**Features:**
- Pendaftaran audit.
- Pengelolaan instrumen audit.
- Pengunggahan bukti dokumen.
- Dashboard monitoring audit.
- Manajemen hak akses pengguna.
- Integrasi penyimpanan Google Drive.

**Tech Stack:** Laravel, Filament, React JS, MySQL.
